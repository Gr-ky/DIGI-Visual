# Ejericcios UF3

## EC3.1 Identifica las 9 THD 

| Nº | Acronimo / tecnologia | Respuesta |
|---|---|---|
| 1 | IoT | Internet de las Cosas (Internet of things) |
| 2 | Big Data | Análisis y gestión de grandes cantidades de datos |
| 3 | IA | Inteligencia Artificial |
| 4 | Cloud | Computación en la nube |
| 5 | Ciberseguridad | Protección de sistemas, redes y datos digitales |
| 6 | Blockchain | Cadena de bloques |
| 7 | RPA | Automatización Robótica de Procesos |
| 8 | Fabricación aditiva | Fabricación de objetos mediante impresión 3D |
| 9 | AR/VR | Realidad Aumentada / Realidad Virtual |

## EC3.2 Quién es quién

| Nº | Situación | THD |
|---|---|---|
| 1 | Un script lee correos, descarga PDFs y extrae datos para rellenar un ERP. | RPA |
| 2 | Tres empresas comparten un registro de certificados académicos sin confiar en una autoridad central. | Blockchain |
| 3 | Una consultora audita aplicaciones web y hace pruebas de penetración. | Ciberseguridad |
| 4 | Una startup lanza su producto sin comprar servidores propios. | Cloud |
| 5 | Un almacén imprime la pieza exacta de una máquina cuando esta se rompe. | Fabricación aditiva |
| 6 | Una consultora forma equipos de ciberseguridad en simulaciones inmersivas. | AR/VR |
| 7 | Un sistema de analítica de logs detecta patrones de ataque en millones de eventos por segundo. | Big Data |
| 8 | Sensores en una planta envían datos de temperatura a una plataforma en la nube. | IoT |
| 9 | Un asistente virtual resuelve dudas frecuentes de una app. | IA |

## EC3.3 ¿Qué THD resuelve qué problema de negocio?

| Problema de negocio | THD propuesta | Justificación |
|---|---|---|
| Tenemos millones de logs pero no sacamos conclusiones operativas. | Big Data | Permite analizar grandes cantidades de datos y encontrar patrones útiles. |
| El soporte técnico pierde demasiadas horas en preguntas repetitivas. | IA | Un asistente virtual puede responder automáticamente a las preguntas frecuentes. |
| Debemos garantizar que un certificado digital que emitimos no se falsifique. | Blockchain | Permite registrar y verificar certificados para detectar modificaciones o falsificaciones. |
| Queremos ofrecer un producto sin invertir en CPD propio. | Cloud | Permite utilizar servidores en la nube sin comprar infraestructura propia. |
| Queremos analizar imágenes de productos para detectar defectos visuales. | IA | Puede analizar imágenes y detectar defectos automáticamente. |
| Queremos simular entornos industriales para formar personal técnico. | AR/VR | Permite practicar en entornos virtuales sin utilizar máquinas reales. |

## EC3.7 Mejoras IT y OT gracias a las THD

| THD | Mejora IT | Mejora OT |
|---|---|---|
| IA | Analiza datos del ERP para predecir la demanda y mejorar los pedidos. | Utiliza datos de sensores para ajustar la producción a la demanda prevista. |

## EC3.8 Plan de futuro: ¿qué THD priorizo?

**1. ¿Qué tres THD elijo?**

Elegiría Inteligencia Artificial (IA), Cloud y Ciberseguridad.

**2. ¿Por qué?**

- **IA:** permite automatizar tareas y crear asistentes virtuales para empresas.
- **Cloud:** permite ofrecer aplicaciones por Internet sin comprar servidores propios.
- **Ciberseguridad:** ayuda a proteger los datos y los sistemas de los clientes.

Estas tres tecnologías se complementan y son adecuadas para una consultora pequeña de 8 personas con presupuesto limitado.

**3. ¿Qué producto o servicio ofrecería?**

Crearía un servicio de asistencia técnica para pequeñas empresas mediante un chatbot con IA alojado en la nube y protegido con medidas de ciberseguridad. Los clientes pagarían una cuota mensual por utilizarlo.
